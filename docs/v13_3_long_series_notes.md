# 동네 알기 v13.3 — 2015~2024 SGIS 장기 인구 시계열

## 무엇을 변경했는가?
- 기존 v13.2의 "2023→2024 한 해 증가폭을 매년 반복" 시나리오를 삭제했습니다.
- SGIS 같은 인구 계열의 2015, 2016, … 2024 **10개 연도가 실제로 확보된 경우에만** 선형 시나리오를 표시합니다.
- 흥해읍 시계열과 북부생활권(7개 읍면) 시계열을 별도 차트로 표시합니다. 2030년 계획 인구 122,000명은 **북부생활권 전체**의 목표입니다.
- 인구 수치는 `src/data/sgis-population-2015-2024.json`을 사용하며, 없는 연도는 자동으로 보간하거나 만들어내지 않습니다.

## SGIS 자료 받는 방법
1. https://sgis.mods.go.kr/ 에서 로그인 → 자료제공 → 자료신청.
2. 통계자료는 **집계구·행정구역별 인구·가구·주택** 중 **행정구역 인구총괄(총인구)**를 선택합니다.
3. 대상 지역은 경상북도(37); 대상연도는 **2015~2022** 각각을 신청합니다. 이미 확보한 2023·2024를 포함하면 10년입니다.
4. 2015~2022년 원본 ZIP을 `SGIS_raw/` 폴더에 모으고 (압축 해제 불필요; 2023~2024년 원자료에서 추출한 7개 읍면 수치는 프로젝트에 이미 포함) 다음을 실행합니다:

   ```powershell
   python scripts/build_sgis_population_series.py --input ".\\SGIS_raw"
   npm.cmd run dev
   ```

5. `sgis-population-2015-2024.json`이 자동 갱신됩니다. 연도가 모자라면 해당 연도를 화면에 명시하고 추세 계산은 보류합니다.

## 추세 시나리오 정의
- 10년 기울기: SGIS 2015~2024년(10개) 선형 회귀 기울기를 2024년 기준으로 2030년까지 연장.
- 최근 5년 기울기: SGIS 2020~2024년(5개) 선형 회귀 기울기를 2024년 기준으로 2030년까지 연장.
- 확률적 인구 예측이나 2030 계획 달성 가능성을 과학적으로 확정하는 수치가 아닙니다. 표에는 "계획 인구 대비 단순 수치 비율"이라고 표시합니다.
- **연도별 행정경계가 바뀐 지역의 자료는 단순 합산만으로 직접 비교할 수 없습니다.** 원자료 코드 및 경계 개편을 검토하고 필요하면 동일 경계 재집계해야 합니다.

## 인구 정의 및 기타 주의
- SGIS 2024는 인구주택총조사 계열(등록센서스 기반) 통계이며, 도시기본계획에 사용된 2015년 통계연보 인구와 정의가 다를 수 있습니다.
- SGIS 2015~2024년 데이터는 같은 통계서비스의 시계열이지만 자료 간 경계/집계 방법 차이까지 없다는 뜻은 아닙니다.
- 2015년 도시기본계획 북부생활권 인구 55,674명은 계획서의 과거 기록으로 구분합니다.
- 2030년 계획 인구 122,000명은 상위 북부생활권(7개 읍면) 기준이며 흥해읍 단독 목표로 표시하지 않습니다.

### 사용한 연도별 원자료
- 2023년과 2024년은 기존 사용자가 내려받은 SGIS 원본 ZIP에서 **직접 재검증**했습니다.
- 2015~2020, 2022년은 사용자가 제공한 SGIS 원본 ZIP에서 추출했고, 기존 2023·2024년 자료와 합쳐 **9개 연도**를 확보했습니다. **2021년은 미확보**입니다. 그래프는 2020~2022년 구간을 연결하지 않으며 전망 숫자는 보류합니다.
- 2015년 흥해읍 SGIS 총인구 36,949명과 계획서 수록(당시 통계연보) 인구 34,642명은 정의·출처가 달라 구분합니다.
- 2015~2020, 2022 원본 파일: `_census_reqdoc_1794047542004.zip` (경상북도 행정구역별 인구총괄 총인구).
