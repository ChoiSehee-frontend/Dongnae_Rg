# 포항 도시기본계획 시각화

React, TypeScript, Vite, Leaflet 기반의 지도형 첫 화면입니다. 포항 행정경계 GeoJSON, 도시개발사업 위치, 인구·환경 통계는 아직 앱에 연결되어 있지 않아 사실처럼 보이는 경계나 사업 위치·수치를 만들지 않습니다. 시·도/포항 선택은 참고 좌표로 지도를 이동시키며, 지도 타일과 저작자 표시는 OpenStreetMap을 사용합니다.

## 설치와 실행

필요 조건: Node.js 20.19 이상 또는 22.12 이상, npm

```bash
npm install
npm run dev
```

Vite가 출력한 로컬 주소를 브라우저에서 엽니다. 배포용 빌드는 `npm run build`, 빌드 결과 미리보기는 `npm run preview`를 실행합니다.

## 포항 시범 화면
전국 → 경북 → 포항을 선택하거나 포항 바로 보기를 사용합니다. 상단 경로로 돌아갈 수 있습니다.
Windows PowerShell에서 npm.ps1이 차단되면 npm.cmd ci, npm.cmd run dev를 사용합니다.

## 데이터 교체
- src/data/administrative-boundaries.geojson: geoBoundaries gbOpen KOR 단순화 자료. ADM1 Natural Earth(2021, Public Domain), ADM2 geoBoundaries/citypopulation.de(2020, CC BY 3.0). 원본 속성에 한글 이름을 추가하고 ADM2 중 Pohang-si만 추출. 경위도 GeoJSON 순서 [경도, 위도]. 권리·기준연도·다운로드 주소는 boundary-sources.json 참조. 경계와 현재 통계 시점은 다르며 최신 행정구역 판정용이 아닙니다.
- regions.json: 지도 이동용 참고점과 표시명. 과거 경계 단위와 대응하며 통계기관 코드가 아닙니다.
- population.json: 2026-09 말 전국·경북 주민등록인구와 포항시 내국인 집계. 지역별 출처 제공. 외국인 포함 총계와 구분합니다.
- city-series.json: 포항 인구 연도별 표와 2023년 상수도 실제값. 연속 자료나 비교 가능한 계획 목표가 없으면 목표선 및 달성률을 그리지 않습니다.
- projects.json: id 유지. position은 검증 전 null, 검증 후 Leaflet [위도, 경도]. 공식 원문 url을 함께 넣습니다. events.json은 projectId로 연결하며 date는 고시일입니다. 현장 착공·준공 증거와 구분합니다.
- 시민 메모는 이 브라우저의 localStorage에 사업별 저장합니다. 서버 제출·타 기기 공유 기능은 없습니다.
- SGIS나 키 없이 동작합니다. 확인되지 않은 Shapefile은 포함하지 않습니다. OSM 타일은 인터넷 연결이 필요합니다.

### 화면 개편
선택 지역의 인구와 기준일은 지도 위에 표시합니다. 포항에서는 사업 목록을 먼저 선택한 다음 고시 기록을 읽습니다. 사업 좌표는 검증 후 등록합니다. 경계는 시·도 2021 / 포항 2020 기준이며 현행 행정구역과 다를 수 있습니다. 상수도 후보와 시민 메모는 기본 화면에서 제외했습니다. 기존 저장 메모를 삭제하지 않습니다.

### 시민용 사업 이야기
포항 사업 목록에서 #project/gokgang 등으로 이동합니다. 설명은 src/data/stories.json에서 질문·답변·근거 문서의 항목별로 관리합니다. 사업 종료 예정일, 현장 준공, 시설 개방을 구분합니다. 원문 링크는 상세 화면 하단의 접힌 근거 목록에 둡니다.

### 동네 탐색
포항 선택 시 29개 읍·면·행정동을 지도 또는 목록에서 선택합니다. #town/{행정기관코드}는 새로고침·공유 가능한 주소입니다. 검색 별칭(예: 곡강리)은 일부 수록한 이름이며 지오코딩이 아닙니다. 흥해읍 정기장 안내와 포항시 전체 예약·행사 안내를 구분합니다. 미확인 통제 일정과 임시 행사는 표시하지 않습니다.

## v10: 동네별 SGIS 통계·공원 목록 연결 (기존 v9 보존)

- `src/data/town-metrics.json`: 포항 29개 읍·면·동의 2023·2024년 SGIS 인구·가구·주택(거처) 데이터 및 2030 기본계획 근린생활권 **참고 연결**.
- `src/data/parks.json`: 전국도시공원정보표준데이터에서 포항시 205개 공원 좌표·유형·면적·주소를 추출한 목록(원본 기준일 2026-05-12). 전체 도시공원 총수와 일치하는 자료가 아닙니다.
- `src/TownData.tsx`: 읍면동 화면 오른쪽 패널의 연도별 그래프·출처·계획생활권 설명.
- 읍면동 지도에 개별 공원 마커 및 목록 추가, '공원 마커 숨기기/표시' 기능. 기존 v9 프로젝트·현재 위치·고시·사업 상세 기능은 유지합니다.

**해석 주의:** SGIS 총조사 인구와 주민등록인구를 섞어 사용하지 않습니다. 계획생활권은 읍면동에 기계적으로 재배정한 참고 매핑으로, 읍면동별 목표치를 뜻하지 않습니다. 2023/2024 SGIS 통계와 2026년 공원 CSV는 서로 기준시점이 다릅니다. 기존 지도 경계는 v9의 2026년 경계를 유지하며, SGIS 인구는 행정코드(`adm_cd`)를 기준으로 연결합니다. 원본 CSV의 재배포 조건은 공개 배포 전 재확인해야 합니다.

## v11 — 동네알기 4단계 탐색 (2026-11-07)

v10.2의 공원 SVG 마커, 지도, 동네 선택을 유지하면서 동네 상세 화면 오른쪽 패널을 다음 흐름으로 구성했습니다.

1. **우리 동네는 지금?** — SGIS 2024년 인구·가구·주택·거처 현황, 2026년 5월 수록 공원 목록, 지도 장소 탐색
2. **어떻게 계획됐을까?** — 2030 포항 도시기본계획의 3개 지역생활권·18개 근린생활권 주 기능(표 4-8·4-13), 해당 상위 생활권의 2030 공원계획(표 10-22), 확인된 관련 사업
3. **실제로 무엇이 달라졌을까?** — SGIS 2023~2024년 변화 막대그래프, 확보한 사업별 공식 고시 이력 및 문서상 상태
4. **나는 어떻게 생각할까?** — 장소·경험·개선 제안·함께 고려할 이용자를 작성하는 브라우저 로컬 메모

**자료 해석 주의**
- SGIS 인구총조사 인구는 주민등록인구와 정의가 다릅니다. 2023~2024년의 두 시점만으로 장기 추세나 특정 사업의 영향이라고 주장하지 않습니다.
- 2030 계획의 생활권별 공원 목표는 행정동 단위 목표가 아닙니다. 공원 CSV는 수록된 위치 목록이므로 공원 총량 및 달성률 판정에 쓰지 않습니다.
- 계획상 근린생활권과 2024년 행정동 경계는 일치하지 않을 수 있습니다(특히 장량동·환여동).
- 고시 기록은 현장 준공/시설 개방 사실을 의미하지 않습니다. 고시가 발견되지 않은 동네에 사업이 없다고 표시하지 않습니다.
- 의견 메모는 `localStorage`에만 저장됩니다. 서버, 시청, 공개 커뮤니티로 전송되지 않습니다. 개인정보를 요구하지 않습니다.

**출처**: 「2030 포항 도시기본계획」 제4장 118쪽(표4-8)·125~126쪽(표4-13) 및 제10장 445쪽(표10-22); SGIS 2023·2024 읍면동 통계 및 행정경계; 공공데이터포털 전국도시공원정보표준데이터(CSV 기준일 2026-05-12); 토지이음 사업별 고시 링크.
