# 포항 도시기본계획 시각화

React, TypeScript, Vite, Leaflet 기반의 지도형 첫 화면입니다. 포항 행정경계 GeoJSON, 도시개발사업 위치, 인구·환경 통계는 아직 앱에 연결되어 있지 않아 사실처럼 보이는 경계나 사업 위치·수치를 만들지 않습니다. 시·도/포항 선택은 참고 좌표로 지도를 이동시키며, 지도 타일과 저작자 표시는 OpenStreetMap을 사용합니다.

## 설치와 실행

필요 조건: Node.js 20.19 이상 또는 22.12 이상, npm

```bash
npm install
npm run dev
```

Vite가 출력한 로컬 주소를 브라우저에서 엽니다. 배포용 빌드는 `npm run build`, 빌드 결과 미리보기는 `npm run preview`를 실행합니다.

## 화면과 자료 상태

- 전국 시·도 목록에서 지역을 선택하면 지도 중심과 확대 수준이 바뀝니다. 경상북도를 선택하면 포항시 진입 버튼이 나타납니다.
- 포항시를 선택하면 포항 중심의 지도와 사업 데이터 상태를 확인할 수 있습니다.
- 실제 사업 레코드가 등록되면 지도 마커와 사업 목록을 선택해 이름, 계획 요약, 계획상 상태, 출처를 확인합니다.
- 인구와 환경 지표 영역은 현재 값이 없음을 표시하고 있으며, 각 카드에 **예시 데이터** 배지를 표시합니다. 임의의 수치와 추세를 표시하지 않습니다.
- OpenStreetMap 타일은 인터넷 연결이 필요하며, 지도 하단에 저작자 표시가 있습니다.

## 실제 데이터 교체

화면 코드와 자료는 분리되어 있습니다. 아래 파일에 출처와 이용 조건을 확인한 실제 자료를 넣거나 동일한 스키마로 교체합니다.

### 행정 경계

파일: `src/data/administrative-boundaries.geojson`

표준 GeoJSON `FeatureCollection`을 사용합니다. 경상북도/포항시 경계 등 실제 경계의 출처와 이용 조건을 확인한 자료만 추가하세요. 현재 빈 `features` 배열이므로 지도에는 행정 경계를 그리지 않습니다.

### 도시개발사업

파일: `src/data/projects.json`

```json
{
  "projects": [
    {
      "id": "source-record-id",
      "name": "공식 계획서에 기재된 사업명",
      "summary": "출처에 근거한 계획 요약",
      "status": "계획서에 기재된 상태",
      "source": "자료명, 발행기관, 기준일 또는 URL",
      "position": [36.0, 129.0]
    }
  ]
}
```

`position`은 `[위도, 경도]` 순서의 실제 사업 위치입니다. 공식 자료에서 확인한 좌표만 사용하고, 좌표계가 다른 GeoJSON은 WGS84 경위도로 변환한 뒤 등록하세요. 화면은 레코드마다 지도 마커와 상세 정보 및 목록 항목을 표시합니다.

### 인구·환경 지표

`src/App.tsx`의 `Indicator` 카드가 표시 영역입니다. 실제 통계를 붙일 때는 기준 연도, 단위, 출처, 산정 방식을 함께 표시하고 **예시 데이터** 표시는 실제 값으로 교체하세요. 이 저장소에는 현재 통계 수치가 없습니다.

## 별도 경계 파일

저장소의 `dataset1/`과 `dataset2/`에는 `bnd_dong_37011_2025_2Q`, `bnd_dong_37012_2025_2Q` Shapefile 구성 파일이 있습니다. 이 파일들은 포항 지도에서 사용하지 않으며, 앱의 `src/data/administrative-boundaries.geojson`에도 연결되어 있지 않습니다. 현재 저장소 자료만으로는 원 출처와 공개 재배포 조건을 확인할 수 없으므로, 출처·라이선스를 확인한 뒤 공개하거나 앱 데이터로 변환하세요.

## 비밀키와 API

현재 버전은 키 없이 실행됩니다. 향후 SGIS 등 인증이 필요한 API를 연동할 경우 키를 브라우저 코드, `.env`의 `VITE_` 변수, 저장소에 넣지 마세요. 서버 측 환경변수(예: `SGIS_API_KEY`)에 저장하고 서버가 API를 호출하도록 구성합니다. `.env` 파일은 커밋하지 마세요.
